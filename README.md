# ClariFi

ClariFi is a personal finance management application designed to help users better understand their spending habits, organize income and expenses, and make more conscious financial decisions.

The goal of ClariFi is to go beyond a simple expense tracker. The platform transforms financial data into clear and visual insights, allowing users to understand where their money goes and how their decisions affect their financial future.

One of the key features of the system is converting expenses into working time. Based on the user's salary and weekly workload, the system shows how many hours of work a specific purchase represents, encouraging more thoughtful spending decisions.

The application also includes interactive dashboards, financial simulations, and tools that help users track their financial progress over time.

ClariFi is built as a responsive web application and can be installed on mobile devices as an app using Progressive Web App (PWA) technology, providing a convenient experience for everyday use.

## Key Features

- Income and expense tracking
- Financial dashboards with visual analytics
- Expense-to-work-time conversion
- Investment simulation tools
- Category-based expense management
- Receipt scanning with OCR
- Installable as a Progressive Web App (PWA)
